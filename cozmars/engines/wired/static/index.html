🔊 Âm lượng

Cách dùng
  1. Chọn mức âm lượng — thay đổi áp dụng ngay.
  2. Tắt (Mute) = robot không phát tiếng.

👁 Màu mắt

Cách dùng
  1. Chọn preset (gồm Cầu vồng / Đỏ) — đổi ngay.
  2. Hoặc dùng màu tùy chỉnh: kéo thanh / chọn ô màu rồi Áp dụng.

Màu tùy chỉnh

😊 Biểu cảm

Đổi hình mắt procedural. Cozmars chưa ghi danh khuôn mặt người như Vector.

📍 Vị trí

  1. Gõ thành phố / địa danh (vd. Ho Chi Minh City).
  2. Bấm Lưu — dùng cho thời tiết / ngữ cảnh.

🕒 Múi giờ

  1. Chọn múi giờ gần bạn (Asia/Ho_Chi_Minh ≈ Asia/Bangkok).
  2. Bấm Lưu múi giờ.

🌡 Đơn vị nhiệt

Chọn °C hoặc °F rồi Lưu.

🕳 Cảm biến vực

IR sàn. Bật = dừng khi thấy vực.

⚡ Kích thích (stim)

Auto = stim tự nhiên. Low / Med / High giữ mức.

Cập nhật OS

Cách dùng (slot A/B)
  1. Chỉ dùng file cozmars-*-armhf-bundle.tgz (không dùng .img.xz).
  2. Dán URL http/https → bấm cập nhật → đợi thanh tiến trình tới 100%.
  3. Gói ghi vào slot nghỉ; slot đang chạy không bị xoá. Boot lỗi 3 lần → tự rollback.

Quan trọng: Chỉ URL OTA chính thức — nguồn lạ dễ làm hỏng robot.
